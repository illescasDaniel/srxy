Start searching in the right folder

Only the initial value of the existing “Where to search” field changes. The GUI keeps its current layout, labels, browsing, and search behavior. These excerpts isolate that field for review.

Opened from a terminal

$ cd /home/daniel/Documents
$ srxy
srxy
Where to search
Review onlyThe current terminal folder becomes the initial search folder when no path was supplied.

Opened as an installed app

Start menu, desktop shortcut, application launcher, or macOS Finder

srxy
Where to search
Review onlyUse the user’s home folder. Never initialize to the installation folder or the shortcut’s working folder.
Review only · shared rules

An explicit path wins: srxy "registry" /home/daniel/Projects keeps /home/daniel/Projects as the initial folder.

Platform equivalents: home means C:\Users\Daniel on Windows, /Users/daniel on macOS, and /home/daniel on this Linux example.

On startup: no search runs automatically when opening without a query. Restoring a recent search remains a user-triggered action.

Scope: startup value only. These explanatory cards and notes do not appear in the application.
